# Shopping App

Projeto de estudo desenvolvido em Flutter com foco em construção de interfaces modernas, componentização de widgets e exploração de conceitos de UI/UX.

---

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos intermediários de Flutter voltados para interfaces visuais e experiência do usuário.

O foco principal não foi construir uma aplicação completa de produção, mas sim explorar técnicas de layout, navegação e reutilização de componentes.

---

## Objetivos de aprendizado

Durante o desenvolvimento, os principais objetivos foram:

- Aprender composição de widgets
- Praticar construção de layouts complexos
- Trabalhar com navegação entre telas
- Implementar animações visuais
- Explorar personalização de temas
- Melhorar organização de componentes reutilizáveis

---

## Observações

Este repositório é um projeto de estudo e experimentação.

Alguns dados estão mockados/hardcoded propositalmente, pois o foco principal está na camada visual da aplicação, e não em regras de negócio, persistência de dados ou integração com APIs.
